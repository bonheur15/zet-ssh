# Zet-SSH (aka zet-ssh)

**Tagline:** A beautiful, modern SSH TUI workspace: profiles + encrypted vault + tabs + file browser + tunnels — all inside your terminal.

**Install (auto OS/arch):** `curl -fsSL https://raw.githubusercontent.com/bonheur15/zet-ssh/main/scripts/install.sh | sh`

## 1) What Zet-SSH is

Zet-SSH is a cross-platform **Terminal User Interface (TUI)** application built in Go that turns "SSH into servers" into a clean, repeatable workflow without leaving your keyboard.

It combines:

- A **modern TUI** for interactive SSH sessions (tmux-like but integrated).
- A **profile manager** (named connections) with fuzzy search.
- A **secure local vault** (encrypted storage for credentials/keys/secrets).
- A **dual-pane file browser** (SCP/SFTP) for quick transfers.
- A **tunnel builder** (local↔remote port forwards) with visual status indicators.
- A **command library** (snippets, aliases, autofill) accessible via a command palette.

Everything is designed to be **keyboard-driven**, **beautiful**, and **auditable**.

---

## 2) Target users

- **Terminal maximalists:** Users who live in the terminal and dislike switching to GUI apps.
- **DevOps/SRE:** Need to manage many connections and tunnels efficiently.
- **Keyboard power users:** Prefer `Ctrl+K`, `j/k` navigation over mouse clicks.
- **Students/Learners:** Want to see the underlying SSH commands generated by the tool.

---

## 3) Core product principles

1.  **Terminal-First:** Runs anywhere (local, remote VPS, low-end hardware).
2.  **Vault-First:** Secrets are encrypted at rest; nothing in plaintext.
3.  **Keyboard-Centric:** Vim-like bindings for navigation and operations.
4.  **Transparent:** Always show the generated command/log.
5.  **Offline-Friendly:** All config and secrets live locally.

## 4) Key features

### 4.1 SSH Profiles (TUI Manager)

**What:** specific "cards" for connections.

**Profile fields**
- Name, Host/IP, Port.
- Auth: Agent, Key (Vault/Path), Password (Vault).
- Advanced: Agent Forwarding, Jump Host, Keepalive, Env Vars.

**UX behavior**
- **Fuzzy Search:** Press `/` to instantly filter profiles by name or tag.
- **Quick Connect:** Press `Enter` on a result to launch the session in a new tab.
- **Import:** Paste an ssh string (`ssh user@host -p 22`) to auto-create a profile.

### 4.2 Encrypted Vault (Local)

**What:** Secure store for secrets, integrated seamlessly into the TUI.

**Design**
- Single encrypted file `vault.zet`.
- **Unlock UI:** A modal popup in the TUI requesting the master password on startup or timeout.
- **Auto-lock:** Re-locks after N minutes of idleness.

### 4.3 Terminal Sessions (Tabs & Panes)

**What:** A built-in multiplexer experience.

**UI**
- **Tabs:** Displayed at the top or left vertical edge.
- **Panes:** Split the view (Vertical/Horizontal) to see multiple servers or a server + logs.
- **Focus:** Cycle through sessions with `Tab` or `Alt+Num`.

### 4.4 Remote File Browser (TUI FM)

**What:** A Midnight Commander-style file manager pane.

**Capabilities**
- **Dual Pane:** Local vs Remote, or Remote vs Remote (if supported).
- **Navigation:** Arrow keys or `h/j/k/l`.
- **Transfer:** Highlight files and press `c` to copy (upload/download).
- **Progress:** Visual progress bars in the footer.
- **Preview:** Text file preview in a side pane.

### 4.5 Tunnel Builder

**What:** Visual interface for managing port forwards.

**UX**
- List view of active tunnels.
- Form to add new: `[Type] [Local Port] -> [Dest Host] : [Dest Port]`.
- Status indicators (Green/Red) for tunnel health.
- Toggle tunnels on/off with `Space`.

### 4.6 Command Library & Palette

**What:** Snippets and actions at your fingertips.

**Features**
- **Command Palette:** `Ctrl+Shift+P` (or similar) opens a global search for actions ("Connect", "New Tunnel", "Upload").
- **Snippets:** Insert saved commands into the active terminal.
- **Variables:** Prompts user via a TUI input box for `${var}` values before execution.

### 4.7 Transparent Command Log

**What:** A collapsible bottom pane showing Zet-SSH's internal operations.

**Shows**
- "Connecting to 10.0.0.1..."
- "Vault unlocked."
- "Uploaded config.json (45KB)."
- "Generated Command: ssh -L 8080:localhost:80 user@host"

## 6) Architecture (Go + Bubble Tea)

### 6.1 High-level components
1.  **Main Program:** The Bubble Tea event loop.
2.  **State Models:** Profiles, Vault, ActiveSessions.
3.  **SSH Engine:** `golang.org/x/crypto/ssh` wrapper.
4.  **UI Widgets:**
    - `bubbles/list` (Profiles)
    - `bubbles/textinput` (Forms)
    - `bubbles/viewport` (Terminal emulation/Logs)
    - `bubbles/filepicker` (File browsing)

### 6.2 Tech Stack
- **Framework:** [Bubble Tea](https://github.com/charmbracelet/bubbletea)
- **Styling:** [Lip Gloss](https://github.com/charmbracelet/lipgloss)
- **SSH:** `golang.org/x/crypto/ssh`
- **Terminal Widget:** `github.com/charmbracelet/x/term` (or similar vt100 emulator for Go)

### 6.3 Data Formats
- JSON for configuration.
- Encrypted Gob or JSON binary for Vault.

## 7) Data model
(Remains largely same as previous spec, optimized for Go structs)

- **Profile:** Struct with tags, auth config, and TUI-specific settings (color theme).
- **Vault:** Encrypted blob.
- **Snippet:** Command templates.

## 8) Security design
- **Memory:** Minimize time secrets spend in memory.
- **UI:** Password fields use masking `******`.
- **Logs:** Redaction of sensitive strings.

---

## 9) TUI Layout & Keybindings

### Layout
- **Top:** Tabs / Breadcrumbs.
- **Left (Toggleable):** Sidebar (Profiles / File Tree).
- **Center:** Active Terminal.
- **Bottom:** Status Bar / Command Line.

### Key Shortcuts (Configurable, Vim-style default)
- `Ctrl+k`: Open Command Palette.
- `Ctrl+n`: New Tab/Connection.
- `Alt+[1-9]`: Switch Tab.
- `?`: Show Help/Keybindings overlay.
- `Ctrl+\`: Toggle Sidebar.

---

## 11) CLI Integration
The binary `zet` acts as the TUI entry point.
- `zet`: Opens the full TUI dashboard.
- `zet connect <name>`: Opens TUI directly into that session.
- `zet run <name> -- <command>`: Executes command and exits (headless mode).
