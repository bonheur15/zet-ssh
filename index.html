Capabilities

Profile Manager + Quick Connect

Create/edit profiles, fuzzy find, ssh config import, and paste-import from raw ssh commands.

Strict Host-Key Security

Connections fail closed unless host keys are trusted in known_hosts files.

Dual-Pane SFTP Workspace

Browse local/remote trees, preview files, copy in either direction, and cancel live transfers.

Recursive Directory Transfer

Upload/download full folder trees with aggregate byte-level progress indicators.

Tunnel Runtime Manager

Create and control local, remote, and SOCKS5 dynamic forwarding inside the active session.

Updater + Release Pipeline

`zet update` installs latest compatible release artifact from GitHub without leaving terminal.

Under The Hood

Built from the architecture and design docs to keep terminal workflows fast, auditable, and local-first.

Bubble Tea State Engine

Dashboard, session tabs, file mode, tunnel mode, and overlays are coordinated through a single event loop.

Local-First Secret + Trust Controls

Vault encryption (Argon2id + ChaCha20-Poly1305), known_hosts enforcement, and optional agent forwarding.
