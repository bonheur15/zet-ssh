Architecture Snapshot

From the project docs and implementation.

Bubble Tea manages dashboard/session state, with specialized models for file mode, tunnel mode, and overlays. Core SSH and SFTP services are wired through session page logic.
`~/.config/zet-ssh/` stores `profiles.json`, `theme.json`, `vault.zet`, and optional app-local `known_hosts`. Profile/auth data remains local and open-source auditable.
CI and release workflows build Linux/macOS/Windows artifacts for amd64/arm64, published as `zet-<os>-<arch>.tar.gz` and consumed by installer/updater.
